載入速度

SCORING RULE

LCP ×40 + TBT ×30 + CLS ×30（PoC 用 HTML size + 3rd party script + inline style 大小代理）

§ 01 為什麼這個指標重要

LCP（Largest Contentful Paint）是 Core Web Vitals 三大支柱第一個。慢的頁面被 Google 標記「Poor」會被同主題對手吃名次。

§ 02 怎麼改

主圖加 fetchpriority="high" + preload font + defer 非必要 script + 移除巨大 inline <style>。

§ 03 好範例 vs 壞範例

✓ GOOD

本工具首頁 LCP < 1.5s（Astro SSG + Cloudflare CDN）。

✗ BAD

電商首頁載 GTM + Hotjar + FB Pixel + 4 個分析 SDK → TBT > 600ms 直接 fail。
