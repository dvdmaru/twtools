結構化資料

SCORING RULE

有 JSON-LD ×40 + Organization ×15 + Article/BlogPosting ×15 + BreadcrumbList ×15 + WebSite ×15

§ 01 為什麼這個指標重要

JSON-LD 是 AI 引擎理解你站內結構的最快路徑。沒 schema 等於要 AI 用「猜的」抓 author / date / category，常常猜錯或乾脆放棄引你。

§ 02 怎麼改

BaseLayout 注入 site-wide Organization + WebSite + BreadcrumbList，blog post 加 BlogPosting + author + datePublished + dateModified。

§ 03 好範例 vs 壞範例

✓ GOOD

twtools.cc 2026-05-20 落地 site-wide Organization JSON-LD 後，blog GEO score +28、品牌權威 0→75。

✗ BAD

純 HTML 靜態站零 schema → AI 引擎完全不知道作者、組織、發布日期。
