常見問題·FAQ

問過
很多次的
六個問題。

還有想問的?歡迎寄信到 hi@twtools.cc,我們會把常被問的整理上來。

01 真的完全免費嗎?哪天會不會開始收費?
全部工具都免費,未來也不打算把核心功能收費。我們靠不擾人的 AdSense 廣告維持運作,廣告永遠不會擋在你和工具中間。
02 上傳的圖片、PDF 會被存下來嗎?
不會。圖片壓縮、PDF 合併、格式轉換等檔案類工具全部在你的瀏覽器本機處理,檔案不會離開你的電腦。
03 手機可以用嗎?需要安裝 App 嗎?
手機瀏覽器直接用,不需要 App。建議把 twtools.cc 加到主畫面,下次找工具更快。iOS Safari、Android Chrome 都通過測試。
04 匯率、彩券、颱風的資料來源是什麼?
匯率來自 ExchangeRate-API,每日更新;台灣彩券同步官方開獎資料;颱風停班停課即時爬取行政院人事行政總處公告。資料皆有 Firebase 快取加速載入。
05 想提建議或回報 bug 該找誰?
寄信到 hi@twtools.cc,或在頁尾的「意見回饋」連結留言。我們是兩個人的小團隊,回信可能慢一點,但每封都會看。
06 會繼續加新工具嗎?想要的工具沒看到怎麼辦?
會持續新增。目前路線圖上有:圖片去背、QR Code 產生器、所得稅試算、勞退試算、油價查詢。歡迎來信告訴我們你需要什麼。
