森人基層、永續服務 森永堅持台灣優先、弱勢優先、教育優先、環境優先

1、爭取臨時托育中心，「一區一臨時托育據點」減輕育兒負擔；健全幼教補助，普設公辦托嬰，提升私幼品質。

2、強化校園安全，補足駐衛警和電子圍籬；落實小班教學，爭取國中小「情感教育」，社會問題從根本解決。

3、強化雙語教育，擴充國小雙語教育、外語師資及環境，提升下一代國際競爭力。

4、協助弱勢家庭與高風險家庭，簡化通報流程，追蹤後續安全照顧。

5、協助青年創業，提供青創者諮詢服務與業界媒合，爭取提高青年創業補助。

6、強化青年政策，創造友善職場 , 維護勞動權益；加速推動公宅；積極強化新創及微創政策。

7、完善動保政策，關懷生命，打造友善動物城市；擴充專業人力，提升收容中心環境；推動寵物友善場域。愛護動物，為浪浪、毛小孩權益發聲，檢討動物領養機制，爭取動保相關措施，打造動物友善城市、推動特色公園，實現兒童遊戲權。

8、推動安一路、基金一二三路電線、電纜地下化，改善市民生活與居住環境。

9、爭取改善基金一二三路交通及大武崙地區、安樂社區麥金路等區域排水，增強防洪功能。

10、爭取舊安樂社區蚵殼港等各里增設停車空間。

3 號・秦鉦・公報政見（展開全文）

中央選舉委員會公報原件・PDF 第 1 頁・文字層與可見原文核對

一、【長庚捷運站與觀光纜車】安樂區是基隆人口最多的地區（約佔快 1/4）。所以規劃捷運路線可規劃八堵進安樂區往中山區進入基隆站，進入安樂區設置一個〔長庚醫院捷運站〕可行性。以〔大基隆〕的觀光戰略來思考，建立濱海東西線風景區觀光空中纜車。東線可以接海科館和八斗子到九份，西線途中經外木山與萬里到金山。郵輪的國際觀光客也可以很輕鬆地『搭纜車吃美食，上山下海看 101』。

二、【守護自然與強化城市韌性】保護海洋生態，反對台電外木山海域建儲氣槽，危害基隆港航運安全及海洋生態。這幾年在疫情與缺水打擊之下，如何強化醫療抗疫、新建大型儲水庫與防堵近 1/4 的漏水等等。打造基隆為堅強的韌性城市已屬當務之急。

三、【安樂區交通改善計畫】1 ﹑盤點鄰里間閒置公有土地來廣建〔停車格〕，將學校操場增建〔地下化停車場〕。2. 開通各區域之間的〔外環道路〕，以疏解主幹道的車流壓力。3. 大型社區出入口對向道路，設計〔左轉暫停區〕或〔左迴轉道〕以順暢車流。4. 瓶頸路口在尖峰時段採用〔科技執法〕嚇阻違規停車。5. 建議由安樂路二段開通樂利一街，經拓寬後的自強產業道路到〔大華交流道〕。

四、【基金公路塞車問題】短期而言，在上午運用〔分流法〕，將部份車流導向基金三路到萬里以疏緩車流。下午採用〔繞道法〕經大武崙工業區接七安產業道路到七堵大華系統上高速公路。長期可將 62 快速道路採高架工法由大武崙延伸到萬里。

五、【曠宇天開古道縱走風景區】把 ( 劉銘傳隧道 )，( 獅球嶺砲台 ) 與 ( 獅嶺匝雲 ) 結合，推出用一天去體驗山林古道，山海美食和歷史古蹟的國運美食健康之旅。

六、【健康運動園區】在安樂區規畫一個同時擁有〔戶外〕與〔室內〕的運動園區。如此一來，可同時滿足健康陽光下的各類型運動和斜風冬雨時的體適能空間。

七、【安樂圖書藝文大樓】成立基隆市第二座文化中心。這將會是一棟嶄新設計的公民生活大樓，結合了圖書、文藝、休閒、學習與服務的社群公共空間。

八、【安樂新都心】基隆的未來在安樂 , 安樂的發展在產業。安樂區有著基隆市最多的跨區通勤上班族，為何楚材晉用！我們有很好的條件可以發展低密度開發的〔科技研發園區〕與〔文創餐飲園區〕。無論從人數、位置、潛力與都更條件來看，安樂區都可以發展成基隆未來的商業與產業型副都心。

9 號・張之豪・公報政見（展開全文）

中央選舉委員會公報原件・PDF 第 1 頁・文字層與可見原文核對

一、候車空間改善 : 安樂沿線候車空間，過去四年，顯著改善，長庚醫院站擴建，友善人行道，之豪將繼續監督改善。

二、路平品質改善 : 麥金路示範道路計畫，基金一二三路改善計畫，皆在過去四年內陸續推動完工，之豪將繼續監督推動地下管線更換與路面改善。

三、親子特色公園 : 過去四年，成功催生安樂三期 ( 四維 ) 親子公園，基隆市內尚有眾多公園空間安全、品質、可玩性，有提升之空間，之豪將持續監督改善。

四、監督基隆捷運 : 基隆捷運計畫在過去四年內，升级為中運量捷運，目前已在綜合規畫階段預計近期可完成報部報院進行核定。屆時，捷運與基隆各區之間的接駁方案，將會決定基隆市未來之通勤模式，之豪將持續監督捷運進度。

五、推動國際交流 : 過去四年，台灣躍升國際矚目焦點，基隆市在後疫情時代，需要積極拓展國際交流，不僅是商機，更是城市發展之關鍵。之豪將持續監督基隆的國際交流。

六、推動行政改革 : 基隆市行政制度需要在國土規劃與區域整合下，審慎重新思考各種可能性。基隆未來發展之利基關鍵為能否有效創建有效率之機構單位，吸引優質行政擘劃官僚，處理捷運與新市鎮發展之複雜課題，之豪將持續監督行政改革。
