§ 01 什麼時候會用到履歷產生器

履歷不是寫一次就放著的文件,而是會隨求職階段反覆修改的活文件。常見的三個情境:第一是應屆畢業生 / 轉職者首次撰寫,需要從零搭起架構 (基本資料、教育、經歷、技能、專案、語言、證照),不知道排版間距字級該怎麼決定;第二是同時投多家公司,要為不同職缺微調自傳與重點工作經歷,但又懶得每次手動排版 (用 Word 改完一個版本要花 20 分鐘調行高字距);第三是更新近年經歷,半年一年前寫過的履歷只要補上新工作就行,但要重新找原檔、改 layout、轉 PDF 又是一輪麻煩。本工具提供編輯器 + 即時預覽 + 一鍵 PDF 匯出的工作流,搭配 3 種模板與 8 種配色,讓你 30 分鐘內完成一份履歷,半小時內微調出投遞用的特化版本。

§ 02 操作步驟、資料儲存與 AI 潤飾邏輯

本工具的設計分四個資料層,各有明確的隱私邊界:

  1. 履歷資料儲存:瀏覽器 localStorage。你填寫的所有內容 (姓名、職稱、聯絡方式、學經歷、技能、自傳) 自動儲存於瀏覽器本機 localStorage,從不上傳到伺服器,我們沒有用戶資料庫。你關掉瀏覽器再回來,資料還在;你換瀏覽器或清除 cache,資料消失。建議完成後立即匯出 PDF 備份。
  2. 3 種模板:① 經典 (Classic):傳統專業排版,單欄結構,適合大企業、傳統產業;② 現代 (Modern):左側色塊 + 雙欄,視覺感較強,適合科技業、新創、設計類職務;③ 簡約 (Minimal):極簡留白設計,字級層級分明,適合學術界、研究機構、海外申請。三種模板可隨時切換,內容不會丟失。
  3. 8 種配色:藍、紫、綠、紅、橙、青、灰、玫瑰,每種顏色都是經過調色的職場安全色,不會太鮮豔失專業。建議:科技業 / 新創用藍紫青;設計 / 創意用紫橙玫瑰;傳統 / 金融用藍灰;學術 / 研究用灰綠。
  4. PDF 匯出:html2pdf.js 純瀏覽器內。匯出時透過 html2pdf.js (內含 html2canvas + jsPDF) 在你的瀏覽器本機把預覽區轉成 A4 PDF,整個過程沒有任何伺服器參與,連你的履歷檔案都不會經過我們的伺服器。建議瀏覽器用 Chrome 或 Edge,Safari 偶有 PDF 字體渲染問題。
  5. AI 智慧潤飾與自傳生成:Worker 代理 + 不留存。「✨ 潤飾」與「✨ 寫自傳」功能透過 Cloudflare Worker 代理 OpenAI gpt-4o-mini API,僅送出你選取的文字片段 (不是整份履歷),加密連線,呼叫完即丟。Worker 端有 IP 限流 (每日 20 次),避免濫用。OpenAI 端依其 API 政策不留存不用於訓練。

§ 03 實際使用情境與常見問題

幾個典型使用流程:應屆畢業生先填基本資料 + 教育經歷,看哪個模板比較順眼,再針對個人專案、社團經歷、實習補強;轉職者複製貼上原本 Word 履歷的內容,選擇現代模板強化視覺,用 AI 潤飾把舊版工作描述改寫更精準;接案族需要快速為每個提案做客製化版本,留一個「全版本」存 localStorage,投遞前複製為特化版微調再匯出 PDF。下面整理最常被問到的疑問。

01為什麼資料只存在瀏覽器?不能跨裝置同步嗎?
資料只存 localStorage 是刻意的隱私設計。履歷包含姓名、身分證後四碼、學歷、工作經歷、薪資期望等高敏感資料,我們不想要 (也不應該擁有) 這些資料的伺服器副本。代價是無法跨裝置同步,但我們提供更安全的替代方案:① 完成後立即匯出 PDF 存到自己的 Google Drive / Dropbox / 本機,跨裝置取用;② 在新裝置重新填一次 (從 PDF 複製貼上重要欄位,通常 5-10 分鐘);③ 編輯器內提供「匯出 JSON」功能 (預計後續版本) 讓你下載結構化資料檔到本機,搬遷時直接匯入。對於想要伺服器同步的用戶,建議使用付費履歷服務 (如 Resume.io、Novoresume) ——付費換隱私風險,自己評估。
023 種模板怎麼選?要符合 ATS (履歷篩選系統) 嗎?
模板選擇看投遞對象:大企業、銀行、傳統產業建議「經典」模板,單欄結構、保守排版,人資看起來最舒服,ATS (Applicant Tracking System) 解析也最穩定;科技業、新創、設計類建議「現代」模板,左側色塊讓視覺有層次,適合需要 portfolio 連結的職務;學術界、研究機構、海外申請建議「簡約」模板,字級分明,海外人資較熟悉這種 layout。ATS 提示:雙欄 layout 在某些舊版 ATS 解析會錯位 (現代模板偶有此風險),投遞大企業時若不確定該公司用什麼系統,選「經典」最保險;科技業多數用較新的 ATS (Greenhouse、Lever 等) 對雙欄解析無問題。
03PDF 匯出後字體跑掉 / 排版位移怎麼辦?
PDF 匯出走 html2pdf.js 內含 html2canvas (HTML 轉圖片) + jsPDF (圖片轉 PDF),常見三類問題:① Safari 瀏覽器偶有字體渲染問題 (CJK 中文字體 fallback),改用 Chrome 或 Edge 通常解決;② 內容超過 1 頁時切頁可能落在不適合的位置 (如標題與內文之間),建議在編輯器內精簡內容或調整段落,讓內容控制在 1 頁內 (應屆畢業生) 或 1.5-2 頁內 (有 3 年以上經歷);③ 自訂顏色搭配深色 background 時 PDF 渲染對比不足,建議使用提供的 8 種預設配色 (已調過 PDF 對比度)。如果以上方法都試過仍有問題,可改用瀏覽器「列印 → 儲存為 PDF」(Ctrl+P) 作為備援方案。
04AI 潤飾會把我的履歷拿去訓練嗎?有沒有送整份履歷?
不會,且僅送選取片段。AI 潤飾與自傳生成功能的資料流如下:① 你在編輯器內選取某段文字 (例如某段工作描述),點「✨ 潤飾」;② 僅送出選取的那段文字,不是整份履歷;③ 走 Cloudflare Worker 代理到 OpenAI gpt-4o-mini API,加密連線;④ OpenAI 回傳潤飾後的版本,Worker 傳回瀏覽器,直接替換選取內容。留存政策:Worker 端不留存任何請求內容 (沒有 log 也沒有資料庫);OpenAI 端依其 API Terms 不留存 API 請求內容,且不用於訓練其模型 (有別於 ChatGPT 網頁版的訓練政策)。Worker 設定 IP 限流 (每日 20 次),避免被濫用做免費 ChatGPT 替代品。如果對 AI 完全有疑慮,所有內容仍可手動編輯,AI 潤飾是選用功能不是強制。
