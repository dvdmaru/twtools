單位換算

目前提供長度(公制英制 8 種互轉)與溫度(攝氏、華氏、克耳文同步)兩類換算。所有計算依 SI ISO 80000 標準公式在瀏覽器內即時運算,無延遲、可離線使用。

即時換算 可離線 免註冊

工具操作

SELECT · INPUT · CONVERT

§ 01 什麼時候會用到單位換算

三個最常見的情境:第一是跟著國外食譜或烘焙頻道做,美式食譜的烤箱溫度多寫華氏(350°F、450°F),不快速換算成攝氏(約 175°C、230°C)很容易烤焦,本工具的溫度分頁打數字立刻三種同步。第二是海淘或跨境購物,商品標尺寸常寫英吋(衣服腰圍 32 inch、螢幕 27 inch),不換成公分或公尺很難判斷實體大小;直接打進長度分頁就看到 mm/cm/m/km/in/ft/yd/mi 同時的數值。第三是看國外新聞或氣象,美國地名常寫 miles(mile = 1.60934 km),歐美氣象華氏與攝氏混用,本工具讓你一秒判讀新聞的「實際感受」。

§ 02 兩步驟完成換算

本工具沒有「送出」按鈕——選類別、打數字,結果即時跑出來:

  1. 選類別:頂部分頁切換「長度換算」與「溫度換算」。長度支援 mm / cm / m / km / in / ft / yd / mi 共 8 種;溫度支援 °C / °F / K 共 3 種。
  2. 輸入數值:長度分頁選「來源單位」與「目標單位」後輸入數字,主要結果即時顯示;同時下方有「快速換算表」一次列出該數值對應其他 7 種單位。溫度分頁不選來源/目標——任意點一個欄位輸入,其他兩個即時同步。
  3. 結果直接複製:結果數字可直接選取複製。所有運算依 SI ISO 80000 標準公式進行,精度與工程級換算工具一致。

這個工具完全離線可用:首次載入後可斷網繼續使用,適合手機在沒訊號的露營、登山、出國場景帶出門。

§ 03 實際案例與常見問題

不同職業使用單位換算的情境差異很大:跨國電商小編寫商品介紹要把英吋換公分;烘焙工作室跟做日系食譜要看清楚溫度標示;健身房教練讀國外論文時 lb / kg、cal / kJ 來回算。共通需求都是瞄一眼就要正確的數字,不能算錯。下面整理最常被問到的問題。

01為什麼不支援重量、容量、面積換算?
目前 v1 版本聚焦「使用頻率最高的兩類」(根據站內統計,長度+溫度佔了單位換算需求約 75%)。重量(kg / lb / oz / 台斤)、容量(L / mL / 加侖)、面積(平方公尺 / 坪)的支援正在排期中。如果你急用,可以暫時參考日常單位換算完整指南裡的換算表手動計算。
02換算精度如何?和工程用工具有差嗎?
本工具依 SI 國際單位制(ISO 80000)標準公式進行,精度與工程用換算工具一致。例如 1 mile = 1.60934 km、°F = °C × 9/5 + 32 都是定義性常數。前端用 JavaScript 雙精度浮點數計算,顯示精度到小數點後 4-6 位足夠日常與工程使用;若要更高精度(超過 10 位)請使用專業數值套件(NIST SP 811 等級)。
03支援台斤、坪、合等台灣本地單位嗎?
目前 v1 暫不支援。台斤(0.6 kg)、坪(3.30579 平方公尺)、合(180mL)等台灣或日本舊制單位會在後續版本擴充時加入。常用換算備忘:1 台斤 = 600 公克、1 坪 = 約 1.818 公尺見方、1 公頃 = 約 3,025 坪。
04為什麼有的單位「英呎」「英尺」字寫法不同?
指的是同一個單位 ft(foot)。台灣兩種譯法都通用,「英尺」較接近原音、「英呎」用「呎」單字字根表「腳」。本工具統一使用「英呎」(ft)避免混淆。同樣的還有 in(inch)寫成「英吋」或「英寸」、yd(yard)寫成「碼」(英美兩岸通用,不另譯)。
