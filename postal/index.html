郵遞區號查詢

22 縣市、370+ 鄉鎮市區完整 3 碼郵遞區號對照。按地區查代碼、按代碼查地區、關鍵字搜尋三種模式,中華郵政官方資料,瀏覽器內即時查、可離線使用。

22 COUNTIES 即時查詢 可離線

工具操作

SELECT · LOOKUP · COPY

§ 01 什麼時候會用到郵遞區號

三個最常見的情境:第一是網購填收件地址,多數電商已自動帶出 3 碼,但偶爾遇到表單沒整合 API,還是要手動填;打錯一碼就會延誤一兩天。第二是履歷與文件填寫,求職、銀行開戶、信用卡申辦的地址欄都要求填郵遞區號,本工具可以一秒查到對應的 3 碼。第三是寄掛號信、限時專送,郵局櫃台會手動輸入郵遞區號分揀;若你直接寫對 3 碼,可省去櫃台查詢時間,在繁忙時段這 10 秒可能差很多。

§ 02 三種查詢模式

本工具提供三種查詢方式,對應不同場景:

  1. 按地區查代碼:選縣市 → 看該縣市所有區/鄉/鎮的清單,點代碼直接複製。適合你已知道地區、要找代碼填表的情境(如填履歷、註冊網站)。臺北市顯示 12 區、新北市 29 區、高雄市 40 區(含東沙/南沙群島)。
  2. 按代碼查地區:輸入 3 碼(或 5 碼自動截前 3 碼),立刻列出對應的縣市與行政區。適合你收到包裹單只看到 3 碼,要回查在哪個地區的情境。同一個代碼可能對應多個地區(如 300 含新竹市東區、北區、香山區)。
  3. 關鍵字搜尋:輸入任意地區、縣市或代碼前綴,找出所有符合的結果。適合你只記得部分地名(如「淡水」「中和」)或想瀏覽某代碼前綴下的所有地區(如「20」會列出基隆市、新北市汐止等)的情境。

所有資料是客戶端 bundled JSON,首次載入後可離線使用,亦無任何後端 API 依賴。資料來源為中華郵政官方公告(2026-05-14 同步),涵蓋 22 縣市、370+ 鄉鎮市區。

§ 03 常見問題

3 碼、5 碼、6 碼差在哪裡?本地資料庫如何更新?以下整理最常被問到的問題。

013 碼、5 碼、6 碼郵遞區號的差別?
3 碼對應到「行政區層級」(例:110 = 臺北市信義區),這是最常用的格式,填網站、寫信封基本都用 3 碼。5 碼是 3+2,後 2 碼細分到「投遞責任區段」(街道分段),掛號信與包裹處理較精細;6 碼為 3+3,進一步區分到「街段路弄」級別,主要用於中華郵政內部分揀系統。一般使用者只需 3 碼即可,本工具聚焦在 3 碼查詢。
02為什麼新竹市三個區都是 300?
新竹市的東區、北區、香山區歷史上是合併設置,共用 300 這個 3 碼。要區分時必須用 5 碼(300xx):東區為 30041-30048、北區為 30049-30060、香山區為 30061-30074。同樣的還有嘉義市東區與西區共用 600(東區 60001-60050、西區 60051-60100)。所以同代碼多地區並非錯誤,而是行政劃分的歷史遺留。
03資料庫多久更新一次?
本工具的資料庫(POSTAL_BY_COUNTY)是中華郵政 2026-05-14 公告版本,共 22 縣市、370+ 區。中華郵政偶爾會調整 3 碼編碼(例:行政區改制、新增離島代碼),歷史上每年大約 1-2 次小調整。我們會在更新時同步釋出。若你發現有不對的編碼,歡迎透過頁尾意見回饋告知。
04想列印或匯出完整對照表怎麼辦?
目前 v1 版本不提供匯出 CSV / Excel 功能。若你急用,可在「按地區查代碼」模式逐縣市開啟,瀏覽器 Cmd+P / Ctrl+P 列印當頁。中華郵政官網提供完整 CSV 下載(搜尋「中華郵政 郵遞區號 下載」),本工具的優勢是即時查找體驗:不用下載檔案、不用 Excel 開啟、不用搜尋分頁,選縣市就秒列出整個對照。
