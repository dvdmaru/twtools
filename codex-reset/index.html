    這一頁是什麼、不是什麼

    Tibo 是 OpenAI Codex 的負責人，常在 X 上宣布「要重置大家的 Codex 用量額度」，或在帳號裡放一張可以自己用的重置卡。這些消息只在他的貼文裡，時間又多半用美國太平洋時間講。這一頁把他的公開貼文整理成一條時間線：預告、補充、進度、確認，並把時間換成台灣時間。

    這一頁不是 OpenAI 官方頁面，不讀任何人的帳號，也不知道你的額度實際有沒有恢復；要確認自己的額度，請以 Codex／ChatGPT 裡顯示的為準。我們也不預測他還沒宣布的重置，不評論重置政策。

    狀態怎麼讀

    • 已預告：Tibo 說要重置，還沒到預計時間。
    • 發送中：他說正在發送（例如「rolling out」「50% done」）。
    • 可能已生效：他發了像是完成的貼文，但措辭不明確、未經人工確認，頁面附原貼文讓你自己判斷。
    • 已過預計時間，尚未確認：推算的時間已經過了，還沒看到確認貼文。
    • 應已生效（依時間推算）：預計時間過了 6 小時以上，仍沒有確認貼文。這是推算，不是確認。
    • 已確認：他用明確的話說完成了。確認時間是確認貼文的發文時間，不是額度實際恢復的精確時間。
    01這一頁的資料從哪裡來？
    只有一個來源：OpenAI Codex 負責人 Tibo（X 帳號 @thsottiaux）在 X 上的公開貼文。我們每 15 分鐘讀一次他的新貼文，他剛宣布重置後的 8 小時內改成每 5 分鐘一次，再用語言模型判斷這則貼文是不是在宣布、確認或撤回額度重置。這一頁不是 OpenAI 官方頁面，也沒有讀取任何人的帳號額度。
    02「可能已生效」跟「已確認」差在哪？
    「已確認」是 Tibo 用明確的話說重置完成了，例如「Reset all propagated」。「可能已生效」是他發了一則看起來像完成的貼文，但措辭不夠明確（例如只寫「Done」），模型自己也不確定，而且沒有經過人工確認。我們不把它當成已確認，也不藏起來：照列原貼文、中譯與 X 連結，請你自己判斷。只有他自己發的貼文或回覆他自己的串才會被標成「可能已生效」，回覆別人的閒聊不算。
    03「預計」的時間是 Tibo 說的，還是你們推算的？
    兩種都有，頁面會分開標。「Tibo 原話」那一行是把他說的時間（多半是美國太平洋時間，例如「6pm PST」「by EOD PST」）換算成台灣時間；「本頁推算」是我們依原話時間再多留一兩個小時，或依他以往常在太平洋時間傍晚 16:30–21:30 按下重置的習慣推算出來的窗口。推算只是參考，時間過了也不會自動變成「已確認」，而是先顯示「已過預計時間，尚未確認」，再過 6 小時才改成「應已生效（依時間推算）」。
    04中文翻譯準嗎？
    中譯由語言模型（DeepSeek）產生，可能有誤，請以英文原文為準。每一則都附 X 原貼文連結，頁面只放簡短的原句與中譯，不轉貼整串內容。
    05為什麼日曆只有最近的紀錄？
    X 官方 API 的搜尋只回溯 7 天，所以我們只能從開始監看的那天往後記錄，沒辦法補上更早的重置。頁面上「本頁自某日起記錄」就是我們開始監看的時間，日曆上更早的日子是空的，不代表那幾天沒有重置。
