台灣郵遞區號怎麼查？3 碼、5 碼、6 碼差在哪，一次說清楚（2026）

網購填地址、寄掛號、列印宅配單，都要填郵遞區號。但 3 碼、5 碼、6 碼到底差在哪？什麼時候填 3 碼就夠？本文用最短篇幅講清楚郵遞區號的分級，以及怎麼用一個免費工具快速查到所在地的 3 碼郵遞區號。

網購結帳、寄掛號信、列印宅配單，幾乎每次都會遇到「郵遞區號」這一欄。多數人是隨手填一個記得的數字，或乾脆留空。但其實郵遞區號有 3 碼、5 碼、6 碼之分，用途不太一樣。這篇用最短篇幅把分級講清楚，並示範怎麼快速查到。

一、3 碼、5 碼、6 碼差在哪

台灣的郵遞區號是分級的，碼數愈多、定位愈細：

碼數說明典型用途
3 碼鄉鎮市區層級多數網購、一般表單的基礎
5 碼（3＋2）較舊／歷史慣用格式部分舊資料、舊表單仍可見
6 碼（3＋3）中華郵政現行投遞細分碼（2020 年 3 月起）郵件分揀、大宗寄送、精準投遞

關鍵觀念：3 碼是基礎；中華郵政現行的細分查詢以 3＋3 的 6 碼為主，你也可能看過 5 碼，那多屬於舊制或歷史慣用格式。一般民眾日常寄件、網購填地址，填對 3 碼就足以讓信件正確分揀到你所在的鄉鎮市區（實際投遞仍取決於完整地址與門牌，3 碼不是門牌驗證）；要更精準的投遞細分，再查中華郵政的 3＋3 六碼即可。

所以與其糾結 5 碼還是 6 碼，不如先確定你所在行政區的 3 碼是對的，再依需要補到現行的 6 碼。

二、一個容易誤會的點：同碼共用

3 碼郵遞區號是對應「鄉鎮市區」這一層，不是對應單一門牌。所以會出現多個區共用同一個 3 碼的情況，例如新竹市的東區、北區、香山區都是 300，嘉義市東區、西區都是 600。這很正常——3 碼本來就不是用來精確定位到某一條街或某一個門牌的。

換句話說，3 碼郵遞區號定位到「區」，不會定位到「號」。要寄到正確門牌，靠的是完整地址，郵遞區號只是幫郵局快速分揀的前置碼。

三、用工具快速查 3 碼郵遞區號

記不住自己住的區是幾號很正常。**TWTools 的台灣郵遞區號查詢工具**內建中華郵政官方的 22 縣市、約 370 個鄉鎮市區的 3 碼對照表，提供三種查法：

  1. 按地區查代碼：選縣市 → 看到該縣市所有區的 3 碼，點一下複製。
  2. 按代碼反查地區：輸入 3 碼，列出對應的縣市與行政區（輸入 5 碼會自動只取前 3 碼）。
  3. 關鍵字搜尋：直接打地名（如「信義」），列出所有相符的區與代碼。

工具載入後，查詢在你的瀏覽器本機完成，不會把你輸入的地名送到後端；資料為內建靜態對照表，所以即查即得。

幾個範圍要先知道：

  • 這個工具提供的是3 碼郵遞區號，定位到鄉鎮市區層級，不提供 5 碼/6 碼的投遞細分碼，也無法查到單一門牌。
  • 資料是中華郵政官方的某一時點對照表（內建靜態表），不是即時連線郵局系統；行政區代碼若日後有異動，以中華郵政最新公告為準。
  • 關鍵字搜尋一次最多列出 30 筆結果。

對絕大多數網購、寄件情境，查到正確的 3 碼就夠用了。需要中華郵政現行的 3＋3 六碼（用於更精準的投遞細分），建議直接到中華郵政官網的 3+3 查詢頁查。

四、什麼時候填郵遞區號最重要

  • 寄掛號 / 包裹：填對 3 碼能加快分揀，降低延誤。
  • 網購收件地址：很多平台用郵遞區號自動帶出縣市區，填對能減少地址打錯。
  • 公司行號批次寄送：量大時通常會需要更精細的 3＋3 六碼，或郵局提供的批次資料，建議直接向中華郵政或配合的郵局確認。
